# 数据边界与隐私：怎么证明"数据不出本机"

这份文档只回答一个问题：**医枢运行时，哪些数据留在本机，哪些会发出去，怎么当场证明。**

对应赛事要求：八·1「不得把未公开的业务资料直接输入外部模型或第三方平台」、
八·3「账号密钥不写进公开仓库」、八·6「说明适用范围与局限」、七·B「可复现演示」。

---

## 一、三种运行形态

| 形态 | 怎么开 | 会连外网吗 | 适合什么场合 |
| --- | --- | --- | --- |
| **① 本机模式（数据不出本机）** | `MEDNEXUS_LOCAL_ONLY=1`（或双击 `本机模式启动.bat`） | **不会。**答疑只用教材原文摘录，文献检索、云同步、模型调用全部关闭 | 现场演示"零外发"；处理未经授权的内部资料；断网环境 |
| ② 本机 + 云端模型（默认） | 在 `.env` 配 `MEDNEXUS_API_KEY`，可再设 `MEDNEXUS_ASK_MODEL=1` | 会连你配置的模型服务（如 `open.bigmodel.cn`）与 NCBI | 想要更通顺的回答；数据是可公开的学习内容 |
| ③ 云端托管 | `MEDNEXUS_PUBLIC=1`（服务器上） | 会连同源托管域名与上述服务 | 队友部署的在线预览 |

界面左下角永远显示当前形态：绿色「本机模式 · 数据不出本机」或琥珀「云端模式」，
鼠标悬停能看到**具体会连哪些地址**（本机模式下这一栏是“没有任何出站请求”）。

## 二、数据清单：每一项去了哪儿

| 数据 | 存在哪 | 本机模式 | 云端模式 |
| --- | --- | --- | --- |
| 教材 PDF / 索引 `chunks.jsonl` | 本机磁盘，不进 git | 不出本机 | 不出本机 |
| 你的提问原文 | 本机 `data/learning.sqlite3` | 不出本机 | 提问 + 命中的教材摘录（≤600 字）发给你配置的模型服务 |
| 作答记录、掌握度、学习时长 | 本机 SQLite | 不出本机 | 不出本机（云同步需你主动点“上传进度”） |
| 学习者标识（48 位匿名串） | 浏览器 localStorage + 本机库 | 不出本机 | 云同步时也不上传 |
| 文献检索词 | 本机生成 | 不检索 | 发往 NCBI E-utilities（带 `tool=MedNexusLearning` 标识） |
| 课程大纲 / 组胚标注 | 本机 `data/course_materials/`（不进 git） | 不出本机 | 不出本机 |
| 模型密钥 | `.env`（已被 `.gitignore` 排除） | 不使用 | 只在请求头里出现，不写进日志 |

## 三、现场怎么证明（三步，60 秒）

**第 1 步：看徽标。** 打开首页，左下角是绿色的「本机模式 · 数据不出本机」。

**第 2 步：跑审计脚本。**

```bat
cd /d C:\Users\尸体在说话\Documents\GitHub\Medical_AI
python tools\check_egress.py
```

脚本会先把本机模式打开、把数据库指到临时文件，然后劫持 socket 的连接与域名解析，
依次跑「教材答疑 / 精选题库出题 / 教材章节出题 / 三要点自测 / 文献检索」，
最后打印外网连接次数。正常输出：

```
  教材答疑（含教材片段）              ok             教材摘录
  精选题库出题                   ok             diagnostic
  教材章节出题                   ok             define
  三要点自测                    ok             triple
  文献检索（应被本机模式拦截）           跳过/拦截：InputError 当前是本机模式，文献检索已关闭…
----------------------------------------------------------------
外网连接：0 次
域名解析：无
----------------------------------------------------------------
结论：全部在本机完成，没有任何数据发出去。
```

**第 3 步：断网复跑（可选，最有说服力）。** 拔掉网线或关掉 WiFi，重启服务，
再问一遍「小胶质细胞的功能是什么」——答案、书名、页码、原文摘录都还在，
因为检索走的是本机索引，不依赖任何远程服务。

## 四、评委可能追问的三个问题

**Q：你们不是用了大模型吗？**
A：模型是**可选**的一层，只负责把教材原文摘录组织得通顺；所有事实、页码、术语都来自本机教材索引，
回答还要过“逐字可查 + 页码一致”的校验，过不了就退回摘录。没有模型、没有网络，功能仍然完整，
只是句子更像“摘抄”。这也是我们敢把它当作合规卖点的原因。

**Q：学习时长会不会是编的？**
A：会，必须说清楚。时长来自前端每次 60 秒的心跳累加（单次 1–600 秒，服务端校验范围），
只能证明“页面开着”，不能证明“人在学”。掌握度同样是**基于作答的推算**，不是考试结论。
所以界面上写的是“学习数据”，报告里写的是“建议复查”，不写“已掌握”“已达标”。

**Q：为什么教材 PDF 不在仓库里？**
A：版权与体积。仓库只放生成脚本（`tools/pdf_extract.py`、`tools/build_chunks.py`），
教材由使用者自备并放在本机；没有索引时系统自动降级为“自编学习卡”，不会编造页码。

## 五、密钥与额度

见 `docs/额度与成本.md`。一句话：密钥只放在 `.env`（已 gitignore），不进 PPT、不进视频、不进截图，
每台机器单独配置，泄露了就换一把。

## 六、已知局限（主动写出来，比被问出来好）

1. 本机模式关闭了文献检索，因此“文献漫游”只剩示例与提示，不返回真实文献。
2. 教材页码依赖逐本标定的 PDF 页偏移，换一个出版社或换一版 PDF 需要重新标定。
3. 章节识别是自动 + 人工抽检，个别书的章标题识别不全（局部解剖学 3 章、生理学 9/12 章、生化部分标题被页眉污染）。
4. 组胚题库是从教材正文自动抽的定义句，少量条目术语不够干净（例如以“后一类”开头），需要人工打磨。
5. 没有账号体系：学习者标识由浏览器本地生成，同一台电脑多人共用会混在一起。
