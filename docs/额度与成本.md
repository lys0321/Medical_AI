# 额度、成本与密钥管理

对应赛事要求：八·3「账号与密钥不得写进公开仓库、PPT 或演示视频；应使用环境变量管理，
并设置额度与成本预算」。这份文档把“花多少钱、最多花多少、密钥放哪、泄露怎么办”写清楚。

---

## 一、结论先放前面

- **本机模式的运行成本是 0 元**：检索、出题、判分、答疑摘录全部在本机算，不调用任何付费接口。
- 云端模型只是“让句子更通顺”的可选层，关掉不影响功能。
- 一次答疑（含模型组织）大约消耗 **1 200–2 000 tokens**；出题、判分、掌握度计算**不消耗任何额度**。
- 演示期建议在模型控制台把**日额度设成很小的值**（例如 50 万 tokens/天），把风险锁死。

## 二、按时间算的用量估算

| 场景 | 单次消耗 | 说明 |
| --- | --- | --- |
| 教材答疑（摘录式，本机模式） | 0 | 检索 6 ms，纯本机 |
| 教材答疑（模型组织） | ≈1 500 tokens（输入 1 000 + 输出 500） | 输入是问题 + 600 字摘录 + 系统提示 |
| 精选题库出题 / 判分 | 0 | 规则引擎 + rubric，无模型 |
| 教材章节出题 / 三要点自测 | 0 | 从 `kaodian.json` 抽原文条目，无模型 |
| 教学对话（多轮追问） | ≈1 800–2 500 tokens/轮 | 每轮带证据与对话历史 |
| PubMed 检索 | 0 元 | NCBI 公共接口，只需遵守频率限制 |

按“每天 20 次答疑 + 10 轮追问”估算，一天约 **5 万 tokens**，一个月约 **150 万 tokens**。

## 三、免费额度从哪来

| 渠道 | 额度 | 备注 |
| --- | --- | --- |
| 智谱 GLM-4-Flash | 免费档（当前政策以免登录控制台为准） | 目前 `.env` 里配的就是它，1.4–3.3 秒/次 |
| 阿里云百炼（qwen-turbo） | 新用户赠送额度 | OpenAI 兼容，改三个环境变量即可切换 |
| DeepSeek | 按量计费，价格低 | 兜底用 |
| 硅基流动 / 火山方舟 | 各家新用户额度 | 同上 |
| 学校“大模型农场” | 校内额度 | 需确认是否 OpenAI 兼容、数据是否出校、并发限制 |
| 本机 Ollama（qwen3:4b） | 无限，仅耗电 | 实测 67 tok/s，一句回答 4–7 秒 |

**切换方式**（只改 `.env`，不改代码）：

```ini
MEDNEXUS_BASE_URL=https://open.bigmodel.cn/api/paas/v4
MEDNEXUS_MODEL=glm-4-flash
MEDNEXUS_API_KEY=你的密钥
```

## 四、成本上限怎么设（演示前必做）

1. **在模型控制台设额度**：智谱控制台 → 费用/额度 → 设日限额或总额上限；百炼、DeepSeek 同理。
2. **在本项目里设开关**：
   - `MEDNEXUS_LOCAL_ONLY=1`：彻底不花钱（推荐现场演示用这个）。
   - `MEDNEXUS_ASK_MODEL=0`：答疑走摘录，不调模型（默认就是关）。
   - `MEDNEXUS_CLOUD=0`：教学对话也不走云端。
3. **观察用量**：每次答疑返回里有耗时（`_ms`），异常变慢往往意味着额度或限流出了问题。

## 五、密钥怎么管

| 规则 | 做法 |
| --- | --- |
| 不写进仓库 | 只放 `mednexus/.env`；`.gitignore` 已排除 `.env`、`.env.*`（放行 `.env.example`） |
| 不进 PPT / 视频 / 截图 | 演示前把浏览器地址栏、控制台、`.env` 窗口都切走；截图后检查一遍 |
| 一机一把 | 每台演示机单独申请，泄露只影响一台 |
| 用环境变量注入 | 服务器上不要 `echo` 到文件，用平台的环境变量配置 |
| 泄露就换 | 控制台立刻吊销并重新生成；旧密钥从 `.env` 删除 |
| 提交前自检 | `git ls-files | findstr .env` 应当只看到 `.env.example` |

## 六、隐私与成本的关系（一句话）

**模型不是必需品。**我们把模型放在最外层，做成“可有可无的润色层”，
所以既能零成本、零外发地演示，也能在需要时接更强的模型——
这两件事都不影响“答案能被翻到”这个核心卖点。
